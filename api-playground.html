미리보기를 클릭하거나 탭하면 가속해서 날아가고, 도착 전에 감속합니다. 새 목적지를 고르면 현재 속도를 이어받아 방향을 바꿔요.

이동

moveTo / moveBy

실제 위치에 가속·감속을 적용합니다. 최고 속도를 비우면 기준 시간으로 속도를 정합니다.

좌표는 캐릭터 박스의 왼쪽 위 기준입니다. 이 체험에서는 목적지만 미리보기 안으로 제한합니다. 관성 경로와 제동 위치는 미리보기 밖으로 나갈 수 있으며 화면 경계에서 멈춥니다. 자연 비행의 중지는 현재 진행 방향으로 감속한 뒤 자세를 정리합니다. 낮은 감속도에서는 더 멀리 이동할 수 있습니다.

실제 이동 측정

movementState
속력 · |velocity|0 px/sx 0 · y 0
가속도 · |acceleration|0 px/s²x 0 · y 0

장식적인 기울기가 아닌 DOM 이동의 속도·가속도입니다. 오른쪽·아래 방향이 양수입니다. 새 목적지와 중지 버튼을 번갈아 눌러 관성·제동을 비교하세요.

실행 코드

등록된 <sidekick-avatar id="bot">에 호출하세요. 컨트롤을 바꾸면 다음 호출, 실행 후에는 실제 호출한 코드가 표시됩니다.

      
활동
play / stop
활동을 재생한 뒤 미리보기를 눌러 보세요. 활동·표정은 비행과 동시에 이어집니다. 이동 중지는 활동을 유지하고, stop()은 활동만 중지합니다. 0은 이 체험의 반복 재생 옵션이며 API에는 duration을 생략합니다.

      
외형 전환
transitionTo

      
미리보기 옵션
미리보기는 스크롤해도 고정됩니다. 키보드로 미리보기에 포커스한 뒤 방향키로 이동하거나 Home으로 중앙에 놓을 수 있습니다.
