할 일과 값을 정하면, 그대로 실행할 수 있는 코드가 만들어집니다. 봇은 이 페이지 전체를 돌아다닙니다. 빈 곳을 클릭하거나 탭해서 목적지를 정해 보세요.

1. 할 일 설정

설정

대상과 봇의 같은 정렬점을 맞춘 뒤 X/Y를 더합니다. 양수는 오른쪽/아래쪽. 화면 경계 제한이 적용됩니다. 예: #action-panel, #site-header-brand

끄면 실행 시점의 위치로 한 번 이동합니다. 켜면 이동 중과 도착 후에도 대상의 스크롤·레이아웃 변화를 관성으로 자연스럽게 추격합니다. 빈 곳을 탭하거나 다른 이동을 실행하면 앵커가 해제됩니다.

화면 왼쪽 위가 (0, 0)이며 봇 박스의 왼쪽 위를 지정합니다. 스크롤 위치와 무관한 viewport 좌표입니다. 빈 곳을 탭하면 봇의 중심이 그곳으로 이동합니다.

속도와 시간 설정

현재 엘리먼트와의 앵커 연결을 해제합니다.

해제 후에는 대상이 스크롤되거나 이동해도 더 이상 따라가지 않습니다. 최초 이동은 유지되며, 도착 후 추격 중이면 감속해 멈춥니다. 아래 실행 버튼으로 해제하고, 오른쪽 코드를 복사할 수 있습니다.

상태는 이동 중에도 유지됩니다. 활동 중지와 이동 중지는 별개입니다. 반복 재생은 API의 duration을 생략합니다.

감정은 이동과 행동을 중단하지 않습니다. 일시적인 반응 후 기존 감정으로 돌아옵니다. neutral로 감정 효과를 해제합니다.

페이지 전체에서 마우스 위치를 추적합니다. 터치 기기에서는 외부 마우스 연결 시 확인할 수 있습니다.

양수 yaw는 화면 오른쪽, 양수 pitch는 몸의 윗부분을 보는 쪽으로, 양수 roll은 반시계 방향입니다. 추적과 활동 자세가 추가로 합성됩니다. 고정 방향만 보려면 마우스 추적을 끄고 상태를 still로 설정하세요.

선택한 액세서리 목록으로 교체합니다. 비어 있는 부위의 기존 장식은 제거됩니다.

관성을 가진 비행으로 화면의 경계를 통과합니다. 퇴장이 끝난 봇은 다시 입장할 수 있습니다.
