# Sidekick 0.18.0

## Added

- Runtime accessory plugins with shared eager/lazy loading, attachment frames, owned mesh validation, cancellation-safe equipment and renderer recovery.
- Independent part animation clips with one runtime clock, local play/pause/seek, bounded keyframes and attachment-local transforms.
- A DOM-independent plugin author SDK, standalone ESM/CommonJS/TypeScript SDK distribution, executable starter validation/build workflow and author documentation.
- External catalog asset examples for all six slots: halo, glasses, moustache, bow tie, and mirrored earrings. Authors use the public SDK rather than private runtime imports.
- Bounded paired-eye geometry and append-only surface connectors, named author helpers, original material ranges, and aggregate fitted-equipment budgets.

## Improved

- Live movement destinations follow changing target layout while preserving travel velocity and validating arrival.
- Shopping demo explains its comparison interaction on first use without stealing focus.

## Distribution

- `hanana-kick-sidekick-0.18.0.tgz`: runtime and framework-free author entrypoint.
- `sidekick-browser-0.18.0.zip`: prebuilt browser runtime and examples.
- `sidekick-plugin-sdk-0.18.0.zip`: locally installable author SDK, declarations, examples and licenses.
- `SHA256SUMS`: SHA-256 integrity values for all three archives.

No npm registry publication is part of this release. Existing 0.17.0 files are not replaced. Plugin equipment and part animation clips remain runtime-only extensions and are not serialized by v7 design/scene JSON. Plugins execute only trusted application-owned modules; the SDK does not execute arbitrary remote URLs.
