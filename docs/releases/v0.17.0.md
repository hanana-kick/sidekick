# Sidekick v0.17.0

## Added
- Public speech API: `say` and `clearSpeech`, including interactive speech actions, lifecycle cleanup, and HTML/React examples.
- On-site companion scenarios with contextual speech and coordinated movement.
- Actual example source viewing with live interaction highlights in the API playground.
- Accessible GitHub navigation in the shared site header.

## Improved
- Compact, localized header and Studio layouts.
- Responsive entrance bounds and source-pane highlight scrolling.
- Installation, CDN, and copied examples consistently pin v0.17.0 so the new speech API is available.
